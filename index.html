Stripe Software Engineer Intern, Core Infrastructure Summer 2026 · back in Spring 2027

Worked on the service mesh, which carries every request between Stripe's internal services. Rebuilt its load balancer around power-of-two-choices using the CPU and queue depth each backend reports, instead of routing blind. Overload errors dropped 40% across 50 services at 400M+ requests a day, and teams could cut the spare replicas they kept as headroom, about $200K a year.

02Projects

Herd

Go · Envoy · gRPC · Kubernetes · Prometheus

A load balancer for LLMs running across several GPU servers. It sits in front of them and picks which server answers each request. It prefers a server that already has the prompt cached, so it can skip redoing that work, then the one with the most free memory, and drops low-priority requests when every server is full. On an 8-server benchmark it cut p99 time to first token 55% compared to round-robin. With two slow servers it held at 12.6s while round-robin hit 292s.

Concertify

Go · Python · PyTorch · Node.js · Redis

Ranks upcoming concerts by how much you listen to each artist on Spotify, with thumbs up and down tuning the weights per user. 500+ users. Ticketmaster allows 5 requests a second, so a Redis cache that collapses duplicate requests and a priority limiter that fetches on-screen results first brought the first load from 9s to 2.5s.

Volumetric Cloud Renderer

C++ · OpenGL · GLSL

Real-time volumetric clouds in C++ and OpenGL. Ray-marches through Perlin-Worley noise generated in compute shaders and lights it with a multiple-scattering approximation, which gives the soft, bright edges. Rendering at half resolution with temporal reprojection from the previous frame makes it about 3.5× cheaper with no visible difference.
