01Work

Stripe Software Engineer Intern, Core Infrastructure Summer 2026 · back in Spring 2027

I was on the team that runs Stripe's service mesh, the layer every request between internal services passes through. Its load balancer had no idea how busy a backend was, so it kept sending traffic to servers that were already struggling. I rebuilt it around power-of-two-choices, so it picks two backends at random and sends the request to whichever is less loaded, based on the CPU and queue depth each one reports. Overload errors fell 40% across 50 services that handle over 400M requests a day, and with load spread evenly, teams could drop the spare replicas they had been keeping as headroom, which saved about $200K a year.

The second piece was saturation routing. A backend that's full turns requests away early so the mesh can retry them somewhere else, and when a whole zone runs hot, traffic spills over to the next one. Together they cut p99 latency 23%, and both rolled out behind feature flags in small canary stages with no incidents.

02Projects

Herd

Go · Envoy · gRPC · Kubernetes · Prometheus

A gateway in front of self-hosted LLM servers that speaks the OpenAI API. It sends each request to a replica that already has the prompt cached, or else the one with the most free KV-cache, and sheds low-priority work when everything is full. On an 8-replica benchmark it cut p99 time to first token 55% compared to round-robin, and with two slow replicas it held at 12.6 seconds while round-robin hit 292.

Concertify

Go · Python · PyTorch · Node.js · Redis

Finds concerts near you and ranks them by how much you actually listen to each artist on Spotify, with thumbs up and down tuning the ranking for each person. More than 500 people have used it. The hard part was Ticketmaster's limit of 5 requests a second, and a Redis cache that collapses duplicate requests plus a rate limiter that fetches what's on screen first cut the first load from 9 seconds to 2.5.

Demo Source

Volumetric Cloud Renderer

C++ · OpenGL · GLSL

Real-time volumetric clouds, made to learn graphics. It marches rays through 3D noise generated on the GPU and lights them with an approximation of multiple scattering, which is what gives clouds their soft, bright edges. Drawing the clouds at half resolution and reusing the previous frame for the rest makes it about 3.5× cheaper with no visible difference.
