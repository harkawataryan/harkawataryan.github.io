01Work

Stripe Software Engineer Intern, Core Infrastructure Summer 2026 · returning Spring 2027

Worked on the service mesh that routes traffic between Stripe's internal services. The mesh picked backends in a way that couldn't tell when one was overloaded, so I rebuilt it around power-of-two-choices weighted by the CPU and queue depth each backend reports. Overload errors dropped 40% across 50+ services handling 400M+ requests a day, and the services could stop over-provisioning for their hottest replica, which came to roughly $200K a year.

Then added zone-aware routing that spills traffic to neighboring zones when one gets hot, cutting p99 latency 23%, and ran the production rollout through feature-flagged canary ramps gated on error and latency metrics. No incidents.

02Projects

Herd Go · Envoy · gRPC · Kubernetes · Prometheus

An OpenAI-compatible inference gateway for self-hosted LLM servers. It routes each request by live KV-cache utilization and prefix-cache affinity, sheds and queues by criticality and tenant, spills over to a cloud provider within a budget, and runs as an Envoy ext_proc endpoint picker.

I built it to see whether the Stripe approach holds up when request cost depends on prompt length and what's already cached. On an 8-replica benchmark it cut p99 time-to-first-token 55% versus round-robin, and with two degraded replicas it held p99 at 12.6s where round-robin reached 292s.

Concertify Go · Python · PyTorch · Node.js · Redis

Finds concerts near you and ranks them by how much you actually listen to the artists. Two-stage retrieval and ranking over Spotify listening history and Ticketmaster events, with a Go gRPC ranking service and per-user weights trained in PyTorch from thumbs up and down. 500+ users.

The interesting part was the upstream quota: Ticketmaster allows 5 requests a second, so cold recommendations went from 9s to 2.5s through a single-flight Redis cache, priority rate limiting and async profile warming.

Volumetric Cloud Renderer C++ · OpenGL · GLSL

Real-time clouds, ray-marched through 3D Perlin-Worley noise generated by compute shaders, with a multiple-scattering lighting approximation. The cloud pass renders at half resolution and a temporal pass reprojects each frame against the last, which makes it 3.5× cheaper for the same converged image.

Built mostly to understand real-time graphics. Renders headless through EGL, so the screenshots and CI run on a CPU rasterizer.
